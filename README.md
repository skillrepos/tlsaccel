# Enterprise Leader AI Accelerator — Workshop Materials
**Tech Leader Summit · Wednesday, December 2, 2026 · Full-day workshop (4 × 90 min) · Revision 1.0**

The essential one-day leader's playbook for understanding and applying AI. For managers, project leaders, and business stakeholders who make AI decisions without doing the implementation.

## What's here

| File / folder | What it is |
|---|---|
| `Enterprise-Leader-AI-Accelerator.pptx` | Full-day slide deck (47 slides, TST template) |
| `Enterprise-Leader-AI-Accelerator-script.md` | Speaker script/talking points, one section per slide |
| `labs.md` | All 9 hands-on labs, step by step with copyable prompts |
| `worksheets/` | 3 fill-in worksheets: use-case scorecard, pilot metrics charter, governance playbook + 30/60/90 |
| `codespace-lab/` | Self-contained repo for optional Lab 9 (push to GitHub, then put its URL into labs.md) |
| `anticipated-qa.md` | Instructor prep: likely questions with answers + timing appendix |

## Attendee requirements

- A laptop and any AI assistant in a browser (Claude, ChatGPT, Microsoft Copilot, or Gemini — free tier OK)
- For optional Lab 9: a free GitHub account
- Worksheets printed or open digitally

## Before the session (instructor)

1. Push `codespace-lab/` to a public GitHub repo and replace `<CODESPACE-REPO-URL>` in `labs.md` (Lab 9, step 1).
2. Create one Codespace from it yourself to warm the image and verify the agent runs end to end.
3. Print worksheets (or share the folder).
